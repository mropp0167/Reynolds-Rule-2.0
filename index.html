Scoring rules

These are editable assumptions for defensive production. Each made field goal and extra point counts as 1. Defensive touchdowns count in the TD category, never again in defense.

Passing touchdowns are included in the TD number you enter for each player. Enter all TDs you wish to count, including QB passing TDs.

ESPN leagues can use customized D/ST categories and point rules. This tool tracks common counting stats, plus optional TFL, three-and-outs, and fourth-down stops. Points allowed and yardage allowed are not included because they are not positive counting events. You can set any defensive statistic's weight to zero. Do not double-count a TD in an offensive player's row and the D/ST row.

Overall ranking method

All four categories have equal weight. Higher raw totals rank better in each category. Equal totals share the average rank (e.g., tied for first: 1.5 each). The lowest sum of category ranks is first overall. Tied overall totals share a place; alphabetical team name is used only for display order.

Stats are stored locally in this browser, not uploaded to a server. Export a backup to move devices or avoid losing browser data. Use Sync ESPN week while running the included local server. ESPN access is unofficial; imported values should be checked before sharing rankings.
