DEPLOY ON RENDER
1. Create a GitHub repository and upload index.html, sync.js, server.py, render.yaml from this folder to the repository root.
2. In Render, choose New > Blueprint and connect that GitHub repository.
3. Approve the service and deploy.
4. Open the onrender.com URL Render provides.

NOTE: This uses Render free service subject to availability, sleeping and limits. ESPN must allow public access to the league. Browser data is stored per-device, not shared between members.
